# Fortran 求解器设计

当前数值实现位于 `src/`，所有数值计算均由 MPI rank 主线程完成。MPI 使用 `mpi_f08`，FFTW 使用官方 `fftw3.f03` 接口，没有进程内任务队列或计算线程池。

| 模块 | 职责 |
| --- | --- |
| `main.f90` | MPI 生命周期、时间推进循环、零模式流量修正、输出调度与计时 |
| `config.f90` | 应用配置模式、参数校验、跨 rank 配置一致性与三文件参数格式读取 |
| `toml.f90` | 配置子集的逐行解析、类型化访问、大小写无关查找和键名检查 |
| `mesh.f90` | x 波数、粗/细网格 y 点分块及 Chebyshev 坐标 |
| `fft.f90` | 两个后端共用的归一化、Nyquist 和 MPI 转置 |
| `fft_backend_fftw.f90` / `fft_backend_fftpack.f90` | 编译时二选一的局部变换、持久工作区和初始化 |
| `dns_vector.f90` | 谱导数、梯度、散度、旋度、去混叠乘积和流量积分 |
| `equation_state.f90` / `dns_equations.f90` | Helmholtz/Poisson 求解、影响系数、压力与速度耦合 |
| `dns_timestep.f90` | 非线性项、压力边界、耦合推进和零模式法向速度约束 |
| `initial.f90` | 初场、随机扰动与壁面边界 |
| `io.f90` | 物理场转换、原子替换、文本/二进制场输出与续算校验 |
| `statistics.f90` | 平面矩、在线统计、能量和散度诊断 |

配置解析器只存储单层分节的键值文本，不包含通用 TOML 对象模型或序列化接口。加载时检查语法和重复名称；读取参数时检查标量类型、数组长度和数值范围；`config.f90` 检查字段集合及物理约束。语法范围见使用说明。

## 数据布局与通信

Fortran 第一维连续。谱速度采用 `V(3,0:NXSP,0:NYS,-NZS:NZS)`，标量采用 `P(0:NXSP,0:NYS,-NZS:NZS)`，物理标量采用 `UP(NX,0:NYP,NZ)`。负 z 波数直接使用 Fortran 下界表示，无需偏移访问器。

谱场在 x 波数方向分布，物理场在 y 方向分布。分块将余数分给末尾的 rank，支持不均匀分块。FFT 在 x/z 变换和 y 变换之间用 `MPI_Alltoallv` 转置，显式打包复数元素；转置计数、偏移及通信缓冲在初始化时分配。

x 使用批量 r2c/c2r，z 使用复数 FFT，y 使用 DCT-I。粗网格满谱时按端点权重拆分与合并 Nyquist，乘积网格按谱截断展开与收谱。默认 FFTW 的 plan 在初始化时创建并复用，仅链接普通 FFTW。`CHANNEL_DNS_FFT_BACKEND=FFTPACK` 使用 `legacy/src/fftpack.f90` 的 RFFT/CFFT/COST 内核；薄适配层复用逐线工作区与三角因子表，不链接 FFTW。两种后端共用上述通信、归一化与求解器。

## 计算热路径与工作区生命周期

计算工作区和数组访问方式如下：

- 非线性乘积的物理场工作区采用分量最后的布局，每个分量连续；谱速度采用分量在前的布局，通过 assumed-shape 接口读取带步长的分量，避免隐式打包。
- 梯度、散度、旋度和壁面散度直接遍历原场，直接生成目标场；叉积三个分量在一次物理网格遍历中计算。
- y DCT 直接对 FFTW 分配的复数工作区建立实数视图，以 guru plan 批处理全部实部/虚部、x 和 z 通道；z 变换也由一个 guru plan 覆盖全部 y 平面。单 rank 的转置共享 k/y 存储。
- FFT 正变换预先计算归一化倒数，按元素乘法缩放；反变换仅清零未保留的谱槽位。
- x 变换在调用方与计划缓冲的 FFTW 对齐类别相同的情况下直接执行；不匹配时通过内部工作区回退，防止错误使用 SIMD 对齐假设。
- `solve_modes_fused` 每次处理 8 个相邻 x 模式，融合 RHS 散度、压力求解、压力梯度、三个速度求解、影响系数和 sigma 修正。它只需 `8 × (NYS+1)` 规模的持久 scratch，不生成整个谱场的 RHS/梯度中间量。
- 时间推进历史通过三次 `move_alloc` 交换所有权，不拷贝整场。非线性、融合求解和诊断工作区在初始化时分配，跨时间步复用，结束时调用对应 close 过程；不引入额外的内存池。
- 输出调用只读的反变换入口，直接读取谱场分量，无需额外标量复制缓冲。

`EQSOLVE_PV_2` 等分步接口保留用于初始化及独立对照测试；它们不是生产时间步的热路径。GNU 构建会将向量/时间步模块的隐式数组临时量警告作为编译错误，防止热路径重新引入整场打包。当前程序采用单个网格上下文，模块工作区不支持多个模拟对象并存。`tests/fortran/test_fused_solver.f90` 比较融合/分步路径，另外的 FFT 测试覆盖不同地址对齐和带步长分量的前后变换。

## 零波数约束

`kx=kz=0` 时，两面壁散度约束退化为相关约束。当前实现保留一个独立影响系数条件，随后将零模式法向速度设为两面壁条件的平均，并清零其高阶 Chebyshev 系数。

`channel_dns_legacy` 使用两面壁共享的零波数影响系数，与主求解器的压力差异并非整体常数。`channel_dns_legacy_aligned` 使用与主求解器一致的独立壁面约束，用于相同约束下的精度检查。`tests/fortran/test_zero_mode.f90` 用已知压力梯度及恒定法向速度检查动量关系；结果和适用范围见性能报告。

## 构建与测试隔离

主求解器、参考求解器和约束对齐参考程序各自使用独立的 Fortran module 目录，避免同名 `mesh`、`fft` 和 `eqsolve_pv` 模块混用。参考源文件的校验值见 `legacy/SOURCE_MANIFEST.json`，计时和约束对齐驱动生成在构建目录。

单元测试位于 `tests/fortran/`，端到端及对照测试位于 `tests/tools/`。`BUILD_LEGACY_REFERENCE=OFF` 可关闭 legacy 构建和相应测试；配置解析器直接编入主库，构建不访问网络。

## 源码风格

`src/` 和 `tests/fortran/` 使用大写 Fortran 关键字、两空格块缩进和统一的过程分隔线。声明与执行语句分段，长表达式使用自由格式续行；注释说明计算公式、端点约定和工作区含义。数值类型显式声明，模块使用 `IMPLICIT NONE`。

可用 fprettify 0.3.7 按仓库配置整理格式：

```sh
./format.sh
```

脚本可从任意目录调用，使用仓库的 `.fprettify.rc`。可通过 `FPRETTIFY=/path/to/fprettify ./format.sh` 指定格式化工具。`legacy/` 保持参考源码格式，不参与上述格式化。
