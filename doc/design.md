# C++ 求解器设计

本文描述 `src/` 中已经实现的 CPU / MPI 求解器。构建和运行细节见 [使用说明](usage.md)。

## 数值模型与模块

程序计算不可压缩槽道流，x、z 为周期方向，使用 Fourier 展开；壁法向 y 使用 Chebyshev 展开。速度和压力主要保存在谱空间，非线性项通过物理空间逐点乘积计算。x/z 导数是波数乘法，y 导数是 Chebyshev 系数递推。线性压力、黏性项通过逐 Fourier 模态的 y 向方程求解，壁面条件和不可压缩约束由 tau 求解及影响函数校正处理。

| 模块 / 源码 | 职责及交互 |
| --- | --- |
| [`main.cpp`](../src/main.cpp) | 初始化 MPI，读取并核对各 rank 配置，依次创建网格、变换器和模拟对象；负责计时、错误报告与 MPI 收尾 |
| [`core/params.*`](../src/core/params.hpp) | 解析 TOML 或旧参数文件，校验配置并计算派生参数 |
| [`core/mesh.*`](../src/core/mesh.hpp) | 管理网格、坐标、谱尺寸与非均匀 x/y 分块表，确定零模所属 rank |
| [`core/mpi_context.*`](../src/core/mpi_context.hpp) | 封装通信器和带检查的集合通信；用于配置一致性、变换转置和流量校正 |
| [`core/array4d.hpp`](../src/core/array4d.hpp)、[`solver/fields.hpp`](../src/solver/fields.hpp) | 连续内存四维容器及标量、向量、边界场的形状约定 |
| [`core/cpu_device.*`](../src/core/cpu_device.hpp) | 统一的任务提交、范围遍历、kernel、复制、填充与同步接口；选择线程池或纯 MPI 执行后端 |
| [`fft/`](../src/fft/transforms.hpp) | FFTW plan、波数、归一化权重、粗/细网格变换、MPI 转置与 wisdom 缓存 |
| [`solver/vector_ops.*`](../src/solver/vector_ops.hpp) | 梯度、散度、旋度及物理空间叉积；调用 Device 和 Transforms |
| [`solver/eqsolve_pv.*`](../src/solver/eqsolve_pv.hpp) | 预计算线性求解系数、影响函数和单位压力梯度响应；完成压力与三分量速度耦合求解 |
| [`solver/timestepper.*`](../src/solver/timestepper.hpp) | 计算非线性项及压力壁面条件，调用耦合求解器并修正壁法向速度零模 |
| [`sim/`](../src/sim/simulation.hpp) | 持有当前场和历史场，组织时间推进、初始/壁面条件、流量控制、扰动和统计 |
| [`io/field_io.*`](../src/io/field_io.hpp) | 谱场续算、物理场快照、EKT；支持文本及带元数据的二进制格式 |

CMake 将上述实现分为 `core → fft → solver → timestep` 等静态库，`io` 和 `sim` 组合这些能力，最终由 `channel_dns` 驱动。求解器不负责文件输出，变换器不管理模拟时间和历史场。

## 数据布局与 MPI 分解

谱场的逻辑顺序是 `[kz + NZS][ky][本地 kx][component]`，最右维连续。向量三个分量交错，标量只有一个分量；壁面场将 y 维替换为上下壁两个值。负 z 波数通过 `at_z()` 偏移访问。底层是 `std::vector`，MPI、FFTW 和 I/O 可直接取得指针，避免容器间转换。

物理场每个分量独立存储，顺序为 `[z][本地 y][x]`，x 连续。谱空间按 x 模态分块，每个 rank 拥有完整 y 系数线和保留的 z 模态，因而每个模态的 y 递推及方程求解都不需要通信。物理空间按 y 分块，每个 rank 拥有完整 x/z 平面。

正向变换过程为：

```mermaid
flowchart LR
    P["物理场：本地 y，完整 x/z"] --> X["x: r2c FFT"]
    X --> Z["z: c2c FFT、截谱"]
    Z --> M["pack → MPI_Alltoallv → unpack"]
    M --> Y["y: DCT-I、归一化、收谱"]
    Y --> S["谱场：本地 kx，完整 y/kz"]
```

逆变换反向经过 y、转置、z 和 x，并展开所需 padding。`Mesh` 按余数分配不等长块，`Transforms` 预计算 `Alltoallv` 的数量和位移。单 rank 路径不做 MPI 转置；细网格路径直接复用本地工作区，粗网格路径仍可能进行本地缓冲复制。粗网格用于物理场输出等操作，`NX2/NY2/NZ2` 网格用于非线性乘积；其尺寸与保留模态共同决定截谱/去混叠设置，不能仅因名称为“细网格”就认为它总比粗网格大。

## 一个时间步如何完成

初始化时创建 FFTW plan 和工作区，构造求解器；随后生成初始速度或读取续算场，并设置壁面速度。`Simulation::run()` 每步执行：

1. **时间离散系数。** 第一步采用一阶启动，后续采用二阶多步组合。令 `a0=1/dt, a1=0, b0=1, b1=0`（首步）；其余步为 `a0=2/dt, a1=-1/(2dt), b0=2, b1=-1`。首两步分别调用 `EqSolvePV::setup((a0+a1)*Re)`，之后复用系数及影响函数。
2. **非线性项。** 在谱空间计算 `ω=curl(u)`；将 u、ω 逆变换至非线性网格，逐点计算 `u×ω`，再正变换回谱空间。`TimeStepper` 使用旋度和非线性项构造压力壁面条件。
3. **组装 RHS。** 将当前/上一时刻速度和非线性项组合为 `a0*u + a1*u_prev + b0*NL + b1*NL_prev`；压力边界也按 b 系数组合。旧速度缓冲交换为本步输出缓冲，当前速度成为历史。
4. **耦合求解。** 对每个 `(kx,kz)`，从速度 RHS 局部计算散度，求压力方程；由压力梯度构造三个速度方程的 forcing，再分别做 tau 求解。影响函数及 sigma 校正满足边界和散度约束，最后写回压力与速度。
5. **零模和流量控制。** 修正壁法向速度零模；零模所属 rank 根据固定压力梯度或目标流量，叠加预计算的单位压力梯度响应。多 rank 时广播所得压力梯度。
6. **输出及后处理。** 按 `NDUMFRQ` 保存谱场；按 `NPRNFRQ` 生成一次物理快照，供 EKT、场输出及统计共用。累计步数大于 `Nstat` 时累计统计；满足配置条件时施加扰动。

续算恢复速度、累计步数与时间，多步法历史及统计重新启动。`NSTEPS` 是本次追加的步数。

## 执行、同步与依赖

默认每个 MPI rank 使用进程内单例线程池，`--threads N`（或 `-t N`）指定计算 worker 数，未指定时使用 CPU 总逻辑线程数（检测失败回退为 1）；另有主线程负责控制和 MPI。程序请求 `MPI_THREAD_FUNNELED`，通信在主线程执行。

`CpuDevice` 提交按 FIFO 批次保序：前一批全部完成后才开始后一批，同一批内的独立块可并行。`launch` 也遵循这个顺序。`sync()` 等待已提交任务完成，并传回任务异常。异步任务引用的场和变换工作区必须存活到同步完成，不能由调用方提前改写。

单 rank 路径将旋度、非线性变换、叉积、RHS、求解、校正及缓冲交换提前入队，在步末同步。多 rank 路径在通信前等待本地任务，保持计算与通信依赖；当前转置使用集合通信，并没有实现非阻塞通信重叠。

编译选项 `CHANNEL_DNS_PURE_MPI=ON` 将 Device 改为主线程直接执行，省去任务队列、worker 和 callable 类型擦除；`sync()` 为空操作，FFTW 使用单线程库，线程数参数被忽略。这是编译期选择。

## 访存及计算优化

| 已实现的优化 | 做法和减少的开销 |
| --- | --- |
| 连续场布局 | component、x 在内层，常用 kernel 顺序访问相邻系数；Debug 断言检查下标，Release 消除检查 |
| FFT 工作区及 plan 复用 | 构造时分配粗/细网格缓冲和通信缓冲，复用 FFTW plan；wisdom 缓存降低后续规划成本，避免每次变换申请/释放大数组 |
| 单 rank FFT 简化搬运 | 不做分布式 pack/unpack；复用 y/zx 工作区，归一化与收谱融合，展开时只清零 padding |
| 向量分量直接变换 | FFT 接口接受分量指针和 `spectral_stride=3`，直接访问交错向量场，省去提取/回填整个谱分量的临时场 |
| 算子融合 | 梯度、散度和旋度在 z 平面 kernel 内完成导数及组合；物理叉积一次读取六个输入并生成三个分量，减少独立全场遍历 |
| 求解器局部化 | 每次处理相邻 8 个 x 模态，worker 私有 scratch 按 `[y][lane]` 布局；y 递推保持顺序，lane 内层便于编译器向量化及复用相邻 cache line |
| 求解中间量复用 | 局部计算压力 RHS、压力导数和速度 forcing；已失效输入缓冲复用为输出；影响函数和 sigma 校正融合后只回写最终场，避免多个全场中间量 |
| 历史场交换 | RHS 消费旧历史后用 `std::swap` 轮换速度、非线性项和边界缓冲，避免每步复制整个历史场 |
| 物理缓冲和快照复用 | 非线性乘积缓冲跨步复用；一次输出快照同时提供给场文件、EKT 和统计 |
| 批次调度 | 范围提交按批次持有 callable，合并相邻逻辑块，减少逐元素入队、分块包装与同步次数 |

单 rank 细网格 FFT 的独立平面由 worker 使用单线程 FFTW plan 计算，plan 按输入/输出对齐类别匹配。多 rank x 向批量 FFT 通过 FFTW 官方线程回调使用同一线程池，不额外创建另一组计算线程。y 方向递推、随机数序列及共享文件流写入仍保持必要的顺序。

这些实现减少分配、全场读写和调度，但收益依赖网格、线程绑定及 MPI 布局；当前没有逐项消融数据，不能把总体加速比归因于某一个优化。小网格可能由进程启动、规划和调度主导，大网格还会受到内存带宽与 MPI 全转置影响。

## 验证与性能口径

`./test.sh` 覆盖数组与网格、FFT 解析模态与往返变换、向量算子、耦合求解器、时间步、输出续算、统计和多 rank 变换。`tests/tools/bench_hybrid.py` 测量执行布局耗时，并在独立输出轮检查场和 EKT。

`--timing` 则测量完整时间步循环，取所有 rank 的最大耗时，包含循环内配置的输出、扰动及首两步求解器 setup；排除 FFTW planning、Simulation 构造和初始场准备。它与完整进程计时的口径不同。实测及复现命令见 [性能记录](performance.md)。

详细方程与校正公式见 [数学算法](algorithm.md)。
